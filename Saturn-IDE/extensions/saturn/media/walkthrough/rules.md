# Project rules

`AGENTS.md` (also `CLAUDE.md`, `.saturn/rules/*.md`, `.cursorrules`) is given to every agent in the project: commands, conventions, what not to touch. The **§ Rules** chip in the chat shows which files agents follow.

# 專案規則

`AGENTS.md` 等規則檔會交給專案中的每個 Agent：常用指令、慣例、不要碰的東西。對話標頭的 **§ Rules** 顯示目前生效的規則檔。
