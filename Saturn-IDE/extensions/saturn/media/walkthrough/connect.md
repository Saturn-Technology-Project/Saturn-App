# Saturn is the engine

Saturn IDE talks to the **Saturn app** on this computer: it holds your models and keys, runs the agents, and keeps everything local.

- Models and API keys: *Saturn Settings → Models*
- Agents and their tools: *Saturn Settings → Agents*

# Saturn 是引擎

Saturn IDE 連線到這台電腦上的 **Saturn App**：模型與金鑰、Agent 都在那裡執行，資料留在本機。
