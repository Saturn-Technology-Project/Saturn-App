# Agents in the background

Click **Run in the background** next to Send: the agent works in a new chat on its own git branch while you keep going. **Saturn Agents** in the Explorer lists every agent at work, and you are told when one finishes.

After an agent edits files, Saturn checks them for new errors and has the agent fix them. **Restore to here** on any step undoes from that step on.

# 背景 Agent

按送出旁的 **在背景執行**：Agent 在獨立分支的新對話中工作，你可以繼續做自己的事；完成時會通知你。
