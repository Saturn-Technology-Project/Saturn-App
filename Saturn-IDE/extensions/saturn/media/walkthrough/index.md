# Code index

Saturn indexes the project so agents find code **by meaning**, not only by name — with a built-in embedding model that runs on this computer. Ask in English or Chinese.

Change the model (LM Studio, an OpenAI-compatible service) in *Saturn Settings → General*.

# 程式碼索引

Saturn 用內建、在本機執行的嵌入模型為專案建立索引，讓 Agent 依語意找到程式碼，中英文提問都可以。
