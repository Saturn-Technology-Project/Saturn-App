# Tab completion

Suggestions appear as you type; **Tab** accepts. After an edit, Saturn suggests the next related change nearby — **Tab** jumps to it and applies it.

Choose the completion model in *Saturn Settings → General* (a small fast model works best).

# Tab 補全

打字時出現建議，按 **Tab** 接受；改完一處後，Saturn 會建議附近相關的下一個修改。補全模型在 *Saturn 設定 → 一般* 選擇。
