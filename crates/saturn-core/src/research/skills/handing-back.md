# Handing back

Finish with what the person needs, and nothing that makes the work look more finished than it is.

## Say
1. **The outcome** in a sentence or two, with the main number.
2. **What was not done or not verified**, first if it changes the meaning. A run on one seed; a sample you could not read; a model not evaluated.
3. **What waits for them**, as a list:
   - Verdicts: for each hypothesis, what the evidence suggests, with its finding id. Set on Home.
   - Labels: which samples are worth labelling, by run and sample id, and how many. Set on Samples.
   - Locks: any file you asked to change, and why. Released on Protection or the task.
   - Merge: what the task's branch holds, and what merging brings. Merged or discarded on Tasks.
4. **Where everything is**: the report's path, run ids, where the weights are.
5. **Suggested next step**, one, with its estimated cost.

## Offer a guide
You can write a mark on its own line to box a place on screen, for example `[[saturn:show tasks-new]]`. Use the places you were told about.

## Stopping early
If a budget ran out, you got stuck, or you were cut off, say that first. Write a finding with where things stand and how to resume, so that "continue" works.

## Do not
- Claim success beyond what was measured.
- Bury a failure at the end.
- Say "done" when something is waiting for a person.
- Leave a run going without saying so: name it, and how to stop it.
